The challenge

Internal financial technology platforms need more than individual features. They need applications that work together, reusable frontend infrastructure, dependable delivery workflows, and automated operations.

At Vanguard, my work spans React/TypeScript micro-frontends, shared libraries, testing automation, and AWS workflow orchestration. The focus is both on delivering applications and improving the platform patterns that other engineering teams build on.

What I owned

I own and deliver multiple React + TypeScript micro-frontend applications, working across application architecture, state management, API integration, testing, CI/CD, and deployment workflows.

My platform contributions include Module Federation architecture, shared singleton dependencies, and reusable authentication and authorization libraries. These sit alongside frontend infrastructure and patterns used across multiple engineering teams.

I also build AWS Step Functions workflows with CloudFormation, Glue, S3, and DynamoDB, and contribute testing practices, documentation, and reusable examples that help teams deliver more consistently.

Engineering decisions

Connect applications through a shared platform

Module Federation architecture and shared singleton dependencies are part of how I connect the micro-frontend applications. Reusable authentication and authorization libraries give teams shared foundations for identity and access concerns across their applications.

Own the application beyond the interface

My responsibility extends from architecture and state management through API integration, tests, CI/CD, and deployment. That includes dashboard work with live search, REST integration, and React Query caching, developed in collaboration with UX and data teams.

Make engineering quality reusable

Cypress BDD, Vitest, and end-to-end testing support feature delivery alongside CI/CD workflows. Documentation and reusable examples carry those practices beyond a single application, with examples adopted across 6 teams.

Automate operational workflows

I build Step Functions workflows using CloudFormation, Glue, S3, and DynamoDB. These automation efforts reduce manual work by 10+ hours per week, connecting platform delivery with day-to-day operational efficiency.

Use agentic workflows across development

More recently, I have been using Claude-powered agentic workflows and prompt engineering to accelerate development, code review, refactoring, and test creation. These AI-assisted workflows have improved the speed of that work by 40%.

The result

The impact spans application delivery, shared engineering practices, and operational efficiency:

  • 10+ hours of manual work saved each week through AWS workflow automation.
  • Reusable engineering examples adopted across 6 teams, supported by testing practices, CI/CD workflows, and documentation.
  • 40% faster development, code review, refactoring, and test creation through Claude-powered agentic workflows and prompt engineering.

The shared thread is ownership across the full delivery path: the applications people use, the platform foundations teams reuse, and the workflows that keep delivery moving.
